1. Quick start

1.1 Install

conda activate protein-studio
pip install -e .  # or: pip install protein-studio
conda install -c conda-forge openmm  # if not already installed

1.2 Run a single-residue sidechain truncation (the simplest workflow)

import sys
sys.path.insert(0, "src")

from protein_studio.core.fep import (
    run_amber_mutation_fep, analyze_fep_bar,
    cartesian_restraint_analytical_correction,
)

# Run Lys6 → Ala on ubiquitin, 11-window BAR with mixed-state
energies, neighbors, disappearing = run_amber_mutation_fep(
    pdb_file="examples/1ubq.pdb",
    mutation_residue=5,           # 0-based: Met1=0, ..., Lys6=5
    from_resname="LYS",
    lambdas=tuple(i / 10 for i in range(11)),  # 11 windows, Δλ = 0.1
    n_equilibration_steps=200,
    n_production_steps=1000,
    sample_neighbor_lambdas=True,   # required for BAR
    restraint_k_kJmol_nm2=1000.0,
)
print(f"Disappearing atoms: {len(disappearing)}")

# BAR analysis
total_dg, sigma, per_window = analyze_fep_bar(
    energies, neighbors, kT_kjmol=2.479,
)
print(f"ΔG_FEP (BAR)  = {total_dg:+.2f} ± {sigma:.2f} kJ/mol")

# Position-restraint analytical correction (unrestraining)
corr = cartesian_restraint_analytical_correction(
    n_atoms=len(disappearing), restraint_k_kJmol_nm2=1000.0,
)
print(f"ΔG_restraint  = {corr:+.2f} kJ/mol")

print(f"ΔG_Lys→Ala    = {total_dg + corr:+.2f} kJ/mol = {(total_dg+corr)/4.184:+.2f} kcal/mol")

1.3 What you should see

  • 11 windows × (200 equilibration + 1000 production) MD steps each — runs in minutes to hours depending on system size.
  • A ΔG value in kcal/mol that you can compare against published experimental or computational reference.
  • The framework is fully tested — see tests/test_fep.py for 28 fast tests + 14 slow integration tests.

2. Architecture overview

Alchemical FEP replaces the system's bonded/non-bonded forces with two forces that smoothly interpolate between "fully coupled" (λ = 0) and "decoupled" (λ = 1):

ForceWhat it computesType
LJ CustomNonbondedForce Soft-core LJ for pairs with disappearing atoms + standard LJ for core-core pairs. Bonded-pair exclusions (1-2/1-3). CustomNonbondedForce, CutoffPeriodic, 1 nm cutoff
Coulomb NonbondedForce Coulomb with PME, per-particle charges scaled (1 − is_dis·λ). 1-4 exception list carries AMBER's intrinsic 1-4 LJ (σ_avg, ε_avg) — preserved across the sweep. NonbondedForce, PME, 1 nm direct cutoff, ε = 5e-4

Why split into two forces? OpenMM's CustomNonbondedForce doesn't support PME. Replacing AMBER's NonbondedForce (which does) loses the bulk-water periodic-image Coulomb (~25,000 kJ/mol of attraction). Splitting preserves both: LJ uses the soft-core pseudo-atom, Coulomb keeps the standard AMBER PME treatment.

Tip: For most production FEP runs, use the Reference OpenMM platform instead of CPU. The CPU platform sometimes NaNs at intermediate λ due to a custom-vs-NB force agreement issue with PME. Reference is slower but more numerically stable.

3. API reference

3.1 System construction

build_amber_solvated_system(pdb_file, padding_nm=1.0, ...)

Build an AMBER + TIP3P system from a PDB file. Adds hydrogens, solvates with TIP3P water + ions, applies AMBER ff99SB-ildn.

Returns (system, topology, positions, integrator)

build_amber_mutation_system(pdb_file, mutation_residue, from_resname="LYS", ...)

Build a system with a single residue's sidechain beyond the Cβ marked as alchemical (disappearing). Position restraints on disappearing atoms (default k=1000 kJ/mol/nm²).

Returns (system, topology, positions, integrator, disappearing_indices)

build_ligand_decouple_system(pdb_file, ligand_resnames, ...)

Build a system with every atom whose residue name matches one of ligand_resnames marked as alchemical. Use for protein-ligand binding or any non-residue ligand. Supports optional boresch_kwargs.

Returns (system, topology, positions, integrator, disappearing, boresch_refs)

3.2 Force manipulation

_replace_amber_nb_with_alchemical(system, disappearing_set, lambda_value, alpha_nm2=1.5, cutoff_nm=1.0)

Replace AMBER's NonbondedForce with the split-force pair (LJ soft-core + Coulomb PME). This is the workhorse function — called internally by build_*_system() but exposed for advanced use.

update_coulomb_for_lambda(coulomb_force, n_particles, original_charges, exceptions, is_dis, lambda_value, context=None)

Update Coulomb per-particle charges and exception chargeProducts for a new λ. Call once per λ change before sampling. If context is provided, also pushes the updates into the running context.

_replace_amber_nb_with_split_forces(...)

Lower-level than _replace_amber_nb_with_alchemical. Returns (lj_force, coulomb_force, n_particles, original_params, exceptions, is_dis). Useful when you want to do your own λ-sweep loop.

3.3 λ-sweep drivers

run_amber_mutation_fep(pdb_file, mutation_residue, from_resname="LYS", lambdas=None, n_equilibration_steps=200, n_production_steps=1000, ...)

Run a sidechain-truncation FEP sweep. Default lambdas: 11 evenly-spaced windows from 0.0 to 1.0 (Δλ = 0.1).

Returns (energies_by_lambda, neighbor_energies, disappearing_indices)

run_ligand_decouple_fep(pdb_file, ligand_resnames, lambdas=None, ...)

Run a ligand decoupling sweep. Same interface as run_amber_mutation_fep but with a disappearing set determined by residue name(s). Supports boresch_kwargs for the bound-state sweep.

Returns (energies_by_lambda, neighbor_energies, disappearing_indices, boresch_refs)

3.4 ΔG extraction

compute_bar(u_a_at_a, u_b_at_a, u_a_at_b, u_b_at_b, kT_kjmol=2.479, ...)

Bennett Acceptance Ratio between two adjacent λ windows. All four arrays are per-frame reduced potentials: U_A and U_B evaluated at samples drawn from BOTH state A and state B.

Returns (delta_g_kJmol, sigma_kJmol)

analyze_fep_bar(energies_by_lambda, neighbor_energies, lambdas=None, kT_kjmol=2.479)

Sum per-window BAR ΔG into the total ΔG_FEP. Reads neighbor_energies populated by sample_neighbor_lambdas=True.

Returns (total_dg_kJmol, sigma_kJmol, per_window_list)

analyze_fep_trapezoidal(energies_by_lambda, lambdas=None)

Fallback integration of ⟨U⟩_λ. Not the right estimator for FEP ΔG — useful for visualization only.

3.5 Analytical corrections

cartesian_restraint_analytical_correction(n_atoms, restraint_k, temperature_K, ...)

ΔG of unrestraining N Cartesian position restraints (Boresch 2003 / Deng & Roux 2009 form). Default V₀ = 1 mol/L in nm³.

boresch_analytical_correction(k_r, k_theta1, k_theta2, k_phi1, k_phi2, k_phi3, T)

ΔG of removing the standard Boresch 6-restraint setup (1 distance + 2 angles + 3 torsions).

standard_state_concentration_correction(box_volume_nm3, T)

ΔG for converting the simulation box effective concentration to 1 M standard state.

compute_binding_dg(energies_complex, energies_solution, neighbor_energies_complex, neighbor_energies_solution, boresch_kws, box_volume_solution_nm3, ...)

Assemble the absolute binding ΔG from a double-decoupling FEP pair:

ΔG_bind = ΔG_complex − ΔG_solution
        + ΔG_Boresch
        + ΔG_standard_state

Install the 6-harmonic Boresch restraint (1 dist + 2 angles + 3 torsions) on an OpenMM system. Returns a dict of equilibrium values for logging.

4. Common workflows

4.1 Sidechain-truncation mutation (e.g. Lys → Ala)

from protein_studio.core.fep import run_amber_mutation_fep, analyze_fep_bar

energies, neighbors, disapp = run_amber_mutation_fep(
    pdb_file="examples/1ubq.pdb",
    mutation_residue=5,        # 0-based Lys6 in ubiquitin
    from_resname="LYS",
    sample_neighbor_lambdas=True,
    n_equilibration_steps=200,
    n_production_steps=1000,
)
total_dg, sigma, _ = analyze_fep_bar(energies, neighbors)
print(f"ΔG_Lys6→Ala = {total_dg/4.184:+.2f} ± {sigma/4.184:.2f} kcal/mol")

4.2 Protein-ligand binding ΔG

Double-decoupling: bound-state sweep + free-state sweep.

from protein_studio.core.fep import run_ligand_decouple_fep, compute_binding_dg

# Bound-state sweep with Boresch 6-restraint
energies_c, neighbors_c, _, boresch_refs = run_ligand_decouple_fep(
    pdb_file="complex.pdb",
    ligand_resnames=["LIG"],
    boresch_kwargs={
        "ligand_atoms": [la1, la2, la3],
        "receptor_atoms": [ra1, ra2, ra3],
    },
    sample_neighbor_lambdas=True,
    n_equilibration_steps=200,
    n_production_steps=1000,
)

# Free-state sweep (no Boresch — ligand is unrestrained in solution)
energies_s, neighbors_s, _, _ = run_ligand_decouple_fep(
    pdb_file="solution.pdb",
    ligand_resnames=["LIG"],
    sample_neighbor_lambdas=True,
)

# Assemble
result = compute_binding_dg(
    energies_c, energies_s,
    neighbor_energies_complex=neighbors_c,
    neighbor_energies_solution=neighbors_s,
    boresch_kws={
        "k_r_kJmol_nm2": 41.84,
        "k_theta1_kJmol_rad2": 418.4,
        "k_theta2_kJmol_rad2": 418.4,
        "k_phi1_kJmol_rad2": 4184.0,
        "k_phi2_kJmol_rad2": 4184.0,
        "k_phi3_kJmol_rad2": 4184.0,
    },
    box_volume_solution_nm3=V_box,
)
print(f"ΔG_bind = {result['binding_dg_kJmol']/4.184:+.2f} kcal/mol")
print(f"  complex_dg     = {result['complex_dg_kJmol']/4.184:+.2f}")
print(f"  solution_dg    = {result['solution_dg_kJmol']/4.184:+.2f}")
print(f"  Boresch_corr   = {result['boresch_correction_kJmol']/4.184:+.2f}")
print(f"  std_state_corr = {result['standard_state_correction_kJmol']/4.184:+.2f}")
print(f"  σ              = {result['sigma_kJmol']/4.184:.2f}")

5. Production checklist

  • λ schedule. 11–21 evenly-spaced windows. Δλ ≤ 0.1 for adjacent-window overlap (BAR convergence).
  • Equilibration. 200+ steps per window with the soft-core potential active. Check that ⟨U⟩_λ is stable across the window.
  • Production sampling. 10⁴–10⁵ steps per window for < 1 kJ/mol statistical error.
  • Mixed-state BAR. Always pass sample_neighbor_lambdas=True — without it, BAR can't be applied.
  • Position restraints. Use k=10,000 for protein sidechains; consider Boresch for ligand binding. Compute the analytical correction explicitly.
  • Platform. Reference is the most numerically stable for our split-force setup; CPU is faster but sometimes NaNs at intermediate λ.
  • Standard state. For absolute binding ΔG, always include the standard-state concentration correction.
  • Sanity check. After the sweep, verify total_dg is in a sensible range (a sidechain deletion ΔG is typically ±5 kcal/mol; a binding ΔG is typically −5 to −15 kcal/mol).

6. Troubleshooting

"Particle coordinate is NaN" at intermediate λ

Cause: The soft-core weakened the LJ, and the integrator drifts the disappearing atoms into close contact with their environment.

Fix:

  • Increase restraint_k_kJmol_nm2 (e.g. 10,000 → 50,000).
  • Pre-minimise at λ = 1 before adding restraints (let the atoms find an LJ cavity first).
  • Use the Reference OpenMM platform.
  • Run more equilibration steps before sampling.

"All Forces must agree on whether to use a cutoff"

Cause: Mixing NoCutoff LJ with PME Coulomb doesn't agree on periodicity.

Fix: The split-force setup uses CutoffPeriodic for LJ and PME for Coulomb — both are periodic-aware. Don't override these.

"All Forces must agree on whether to use periodic boundary conditions"

Cause: Same as above. Use the split-force setup; don't manually set nonbonded method.

"The BAR solver gives NaN"

Cause: Insufficient overlap between adjacent λ windows — the exponential-weighting averages overflow.

Fix: Use more λ windows (Δλ ≤ 0.1), longer production, or check for non-equilibrated starting structures.

ΔG magnitude is wildly off (e.g. thousands of kcal/mol)

Cause: You're using trapezoidal on ⟨U⟩_λ — that's not the FEP ΔG; use BAR with mixed-state re-evaluation. See Common workflows.

Wrong sign on ΔG_bind

Check: compute_binding_dg returns ΔG_bind = ΔG_complex − ΔG_solution + ΔG_Boresch + ΔG_standard_state. The standard Boresch correction is negative (unrestraining the ligand decreases free energy). The standard-state correction is also negative (simulation box has higher effective concentration than 1 M).
